
【中转站行业用词 — 中文为主，站名和模型名保留原文】

1. 歧义默认值：以下词按 API 与模型含义翻译，不按日常含义：
   - LLM = 大语言模型
   - Token / tokens = 模型 token（保留英文；不译“代币”或“令牌”，除非原文明确在说登录令牌）
   - API key = API 密钥
   - base URL / base_url = 保留英文 base URL
   - 倍率 = 材料里的分组倍率，保留数字，不改写成“便宜”或“贵”
   - 中转站 / relay / API proxy = 中转站或 API 代理。不要译成“继电器”或“代理人”

2. 站名、上游厂商名、模型名和版本号一律保留原文，不翻译、不扩写：
   - 上游：OpenAI / Anthropic / Google / Gemini / DeepSeek / Qwen / GLM / Mistral / Meta / Llama
   - 模型与版本：GPT、Claude、Gemini、o1 以及材料中的完整型号，一字不改
   - 中转站名字按原文书写，不替换成别的站

3. 数字必须照抄：价格、倍率、时长、错误率和日期。不要把 $3/M 改写成“几美元”，不要把 0.2x 改写成“很便宜”。

4. 代码、命令、URL 不翻译。不要把材料改写成使用建议或站点比较。
