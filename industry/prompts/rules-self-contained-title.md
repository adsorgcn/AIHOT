
【标题自洽规则 — 让读者不点开就知道是哪一家的什么事】

1. 标题必须点出中转站或上游的名字（材料里有才写），以及事件类型：调价、故障、关停、上线、模型上下架、政策或监管。
2. 只写事实，不加评语。不要写“靠谱”“危险”“首选”“不建议”，不要写成排行或劝退。
3. 原标题已经清楚点出主体和事件类型的：英文标题翻译成中文、中文标题保持原意，不要为改写而改写。
4. 原标题只是代号或没有信息量的句子（如 "v2"、"公告"、"紧急通知"）时，结合【来源】和正文把站名和事件类型补进标题。例：来源是某中转站公告、正文写明输入价从 $3 调到 $3.6 → “某中转站上调输入价格”。
5. 补站名只能用【来源】或正文里真实出现的名字。正文和来源都没点出具体站时，用“一家中转站”这类上位词，绝不凭常识编站名、价格或时长。
6. 原标题的文章类型是硬边界：How / Why / Guide / Analysis / Review 这类解释或对照，中文标题必须保留这个类型；不能因为正文提到一次调价或故障，就改写成“发布 / 上线”。只有原标题明确宣布了上线、调价、关停或故障，中文标题才能使用对应动作。
   例：原标题 "How relay X changed its Claude price" → "中转站 X 如何调整 Claude 价格"，不能写成 "中转站 X 上线新套餐"，除非原文就是在宣布新套餐。
